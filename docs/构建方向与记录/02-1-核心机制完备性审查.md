# 02-1 核心机制完备性审查（主线 0.x）

> 状态：**进行中 —— 这是 Phase 1 收敛会的当前第一轮议题**（先于 `03-状态本体`）。
> 目标不是设计，而是回答：「一个持续存在的智能系统，我们目前的四个机制是否覆盖了它必须具备的功能？还缺不缺第五个、第六个？」
>
> 来源：2026-08 讨论确认「四核心 = 完整内核」从已证明事实降级为**第一版功能假设**。

## 一、关键区分：边界 ≠ 模块完备性

| 问题 | 归属 |
|------|------|
| 哪些功能**必须自建**，哪些**交给外部**？ | `02-系统边界`（已定，维持不变） |
| 内核内部**只有这四个机制**够不够？ | **本文件**（完备性/功能分解问题） |

- `02-系统边界` 的答案（内核自建 State/Time/Appraisal/Sedimentation/透明轨迹；借用 LLM 嘴手/载体/CLI）**不因本审查改变**。
- 本次只把「四个机制 = 完整内核」降级为「四个已识别机制 = 当前第一版功能假设」——**不违反任何已关闭 ADR**。

## 二、四个已识别机制的来源（为什么它们很自然，但可能不完整）

来自一条自然的观察链：

```text
状态 → 时间 → 事件评价 → 长期沉积
```

| 机制 | 回答的问题 |
|------|-----------|
| A. State | 「我现在是什么状态？」 |
| B. Time / Temporal Dynamics | 「没有新事情发生，我会不会变？」 |
| C. Appraisal | 「发生的事情对我意味着什么？」 |
| D. Sedimentation | 「经历重复以后，我会不会形成长期倾向？」 |

闭环：`S_t →(Appraisal E_t)→ S_{t+1} →(Time)→ S_{t+Δt} →(Sedimentation)→ P`

> 注意：这个闭环描述的是「**状态如何变化**」，未必完整描述「**一个智能系统如何形成自身**」。记忆/遗忘/学习/抽象正是指出的缺口。

## 三、审查方法：不从「人类心理模块」出发

**反直觉起点（GPT 观点）**：既不该从「人类有什么心理模块」出发，也不该从「LLM 有哪些能力」出发拼装人格系统。

正确路线（已入 `01-协议`）：

```text
观察现象 → 寻找已有理论 → 提取功能 → 判断必要性 → 设计机制 → 选择数学表示 → 工程实现
```

**候选生成法（我的补充）**：从「一个持续存在、能交互、形成个体差异的系统」的**必要功能**出发提问，而不是拍脑袋列表：

```text
它是什么？        → State
它怎么变？        → Time
它为何变？        → Appraisal
它留下什么？      → Sedimentation
它预见什么？      → Prediction？      （缺口候选）
它选择什么？      → Attention？       （缺口候选）
它想要什么？      → Goal / Motivation？（缺口候选）
它知道自己吗？    → Self-model？      （降权相关，谨慎）
它如何应对未知？  → Uncertainty？     （缺口候选）
```

## 四、审查表（逐行待审；第一轮用交叉领域文献过）

| 功能现象 | 人类中是否有证据 | 是否为系统必要功能 | 当前四模块是否覆盖 | 是否需要独立机制 |

| 遗忘 | 强 | 待判断 | ? | 待研究（痕迹降级候选） |
| 学习 | 强 | 很可能 | ? | 待研究 |
| 抽象 | 强 | 待判断 | ? | 待研究 |
| 注意 | 强 | 待判断 | ? | 待研究 |
| 预测 | 强 | 待判断 | ? | 待研究 |

## 五、第一个被审查的现象：信息匮乏滑坡

`研究/01-信息匮乏滑坡` 已被确立为命名现象。它同时涉及记忆/遗忘/抽象/学习四行，作为**审查表的第一个实际用例**：

- 既有防线（写白名单 / 衰减向基线 / 透明轨迹）是否足够？
- 若不足，机制级对策候选：痕迹降级、更新率钳制、解释-结构耦合阻尼。

## 六、复杂度预算（评估新机制时的全局视角）

复杂度不会凭空消失，只会转移：

```text
C_total = C_state + C_dynamics + C_appraisal + C_memory
        + C_computation + C_parameterization
```

- 不问「哪个地方最简单」，问「**整个系统的复杂度被放在哪里**」。
- 例：状态方程简单 → Appraisal 或 Sedimentation 或参数校准承担复杂度；简单数学 → 参数需大量经验校准。
- 此式是**思想工具**，不真算；但它应成为评估每个新机制/新模块的正式问题。

## 七、研究领域（外部研究优先）

| 领域 | 关注 |
|------|------|
| 心灵哲学 | functionalism、computational theory of mind、embodied cognition、predictive processing、self-model、personal identity |
| 认知科学 | memory consolidation/reconsolidation、forgetting、schema、predictive processing、attention、cognitive development |
| 心理学 | developmental psychology、cognitive psychology、learning theory、affective science、appraisal theory |
| 神经科学 | 功能的时间尺度、状态依赖、物理机制基础（不模仿神经元） |
| AI / ML | catastrophic forgetting、continual learning、experience replay、representation learning、world models、state-space models、memory architectures、test-time learning |

> 目的是防「把恰好容易被意识观察到的部分，当成心智全部的因果结构」——不照抄心理学。

## 八、本轮产出与裁决规则

- 逐行收敛审查表 → 决定：已有 / 归属现有模块（属性或关系）/ 新增独立机制 / 暂不决定。
- 每收敛一行 → 回写 `实现路径/` 对应文件 + `005-开放问题`。
- 新增独立机制必须走 `01-协议` 的机制新增管线（现象 → 功能 → 机制 → 模块?）+ 复杂度预算评估。
