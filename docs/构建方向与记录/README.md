# 构建方向与记录 — 实现设计收敛过程

> 本目录是 `agent_personification` 的**实现过程记录区**：记录「实现设计收敛过程」的讨论顺序、安排与已明确的注意点。
> 与 `docs/adr/实现路径/` 的分工：
>
> - **实现路径 = 成果归档**：按「部分 → 整体、正式使用的调用顺序」组织工程决策（选型、数学结构、接口、验收）。

>
> 关系机制：**本目录讨论收敛一项，回写一项**到 `实现路径/` 对应文件（状态从「待裁决」→「已定」），并同步 `docs/adr/005-开放问题.md`。

## 讨论协议速查

- 任何新想法：**先分类（A~G，见 `01-协议`）→ 放回系统 → 判断是否触碰已关闭决策**。
- 每个被接受的讨论项，走横向轴七问：定义 → 假设 → 数学/逻辑 → 实现 → 可观测量 → 验证 → 失败怎么办。
- 已由 ADR 决定的不重谈；需要重开决策必须明确提出（不能悄悄偏航）。
