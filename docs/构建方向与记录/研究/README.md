## 命名约定

- 新的现象/概念一旦被识别并命名（如「信息匮乏滑坡」），在本区建立独立记录，**名称全局稳定**，正文各处引用同一名称。
- 命名格式：短横线分隔、中文为主；研究条目用「研究-」前缀目录名 + 数字序号。
