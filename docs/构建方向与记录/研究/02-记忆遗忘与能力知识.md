# 研究 02 — 记忆、遗忘与能力/知识

> 探索性研究（2026-08）。主题：一个「从无到有」的系统如何记忆、如何遗忘、先验能力与个体知识如何区分。
> 影响对象：`06-长期沉积`（痕迹降级方向）、`02-1` 审查表（记忆/遗忘/抽象/学习行）、`04-状态数学`（衰减语义）。

## 一、人类发展类比（来源：用户观察）

- 早期阶段**记忆会被清除**，但某些**学习模式 / 基础技能 / 思维方式被保留**——它们有物理依据。
- 早期学到的东西必然**极为基础、脱离复杂性与单一层面约束**——是通用性能力。
- 差异：LLM 诞生即拥有海量知识——我们完全忽略了「信息丰富度」问题。一旦开始本地化管理记忆/知识，**数据匮乏必然导致严重错位**。
- 用户判断：把人类当模仿对象 → 物理机制的记忆消除；但文本结构上，消除了便是**完全删除**，不存在物理留存——**除非内核的数学结构能够承担这一部分**。
- 用户立场：这种消除和丢失信息，是**让整个体系获得「真实可运行」的必要手段**（不完全的记忆才是可信的持续个体）。

## 二、能力 vs 知识（关键区分）

```text
能力（capacity）          知识（knowledge）
语言理解 / 推理 / 抽象      用户是谁
类比 / 学习 / 工具使用      我和用户是什么关系
───────┬───────          过去发生了什么
  先验能力结构              如何看待某个事件
                          ───────┬───────
                             个体历史产生的信息
```

系统不是 `Blank Mind + Experience`，而是：

```text
Pretrained Model + Local Experience + Persistent State
```

与人类婴儿的发展过程**根本不同**。不能简单说「LLM 就是它出生时的知识」（那意味着出生即通晓语言/历史/科学/人格理论），也不能把知识全部屏蔽（失去核心能力）。

## 三、信息降级：遗忘的不是「影响」，而是「原始信息」

```text
E（事件）
 ↓
短期痕迹（episodic）
 ↓
统计影响
 ↓
抽象结构（semantic）
 ↓
长期倾向（P）
```

随时间：episodic ↓，semantic 与 P 保留。
比「记忆存在 / 记忆不存在」二值化更有意思，也**比 delete(JSON) 更接近人类记忆**（长期记忆并不完整保存原始经历）。

## 四、数学落点：痕迹分辨率衰减（我的判断）

- **遗忘 = 痕迹分辨率的衰减，不是删除**：原始痕迹（raw trace）的**保留权重随 Δt 指数衰减**——补算天然可实现（Time Engine 已有衰减机制，只是作用对象从状态值扩展到痕迹信息量）。
- 沉积（Sedimentation）保存**统计抽象**；原始事件文本随时间降为不可检索，但影响沉淀在特征里。
- 这正是「**内核的数学结构承担物理机制留存**」（用户直觉）的落点：删除文本是彻底消失，但若痕迹的衰减/抽象由数学结构承担，就实现了「记忆清除、影响保留」。
- 这同时是信息匮乏滑坡（`研究/01`）的对策候选：低分辨率痕迹无法被过度挖取。

## 五、Memory Engine 非决策（暂不新增模块）

- 记忆**可能是 State / Trace / Sediment 三者之间的跨时间尺度关系**，而非独立机制：

```text
Event → Trace → 短期状态 → 沉积 → 长期结构
```

- 硬造 `Memory Engine` 反而可能产生**错误的模块边界**。
- 决定：把「记忆、遗忘、学习、抽象、知识形成」列为**尚未归属的核心功能问题**，进 `02-1` 审查表待研究行；作为**方向之一保留进入后续步骤，而非当成唯一可选方案**。
