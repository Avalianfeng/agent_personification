# 开放问题与路线纷争推演

> 本文件是 ADR 体系中最活跃的部分：尚未落定的开放问题、以及各条路线纷争的推演结果（已判定的标出判定处，未判定的如实标注）。
> 按约定，本体系不假装已定；这里的每一条都可以在未来某个决策文件中获得裁决并移出。

---

## 一、开放问题清单

### 问题 1：状态的数学形态（模块 ①）

Connection 到底是什么：`0~100` 标量？`[-1,1]`？Bayesian belief？图权重？动态系统？需求满足度？

**当前态度**：不靠思辨定案。按 ADR-007，由 Phase 1 最小原型作为讨论载体暴露后裁决。原型先取最简单形态（三个变量、一种衰减），形态本身是 Phase 1 grill 的烤点之一。

### 问题 2：Appraisal 的实现形态（模块 ③）

规则引擎、小模型、还是 LLM 辅助？如何避免评价本身变成 Prompt 表演（评价链路必须可检查，见 ADR-002 后果）？

**当前态度**：规则为主、LLM 辅助可关是方向，但实现形态未定；「评价不直接改状态、先评价后更新」已经确定。

### 问题 3：时间粒度与衰减形态（模块 ②）

秒级 / 分钟级 / 与心跳对齐？各变量随时间的衰减函数（线性？指数？）？

**当前态度**：衰减=时间差纯函数、读取补算无损已确定；具体函数形态未定，属于 Phase 1 讨论范围。

### 问题 4：状态注入格式与 token 预算（模块 ⑤）

状态 → LLM 的注入格式（结构化摘要 + derived hints）、token 预算、以及「Cognition 如何成为状态中的真实事件而非提示词执行」。

**当前态度**：方向已定（结构化注入、纯函数渲染、禁止模型改真相）；格式细节未定，Phase 2 时裁决。

### 问题 5：Sedimentation 的量化（模块 ④）

痕迹 → 强化 → 稳定特征的门槛数值、状态机细节、修改门槛（习惯 < 特征 < 核心原则）的量化。

**当前态度**：滞后、惯性、门槛递增的方向已确定；量化未定，Phase 4 时裁决。

### 问题 6：非文字之墙（模块 ⑩）

输入（感官事件进不来）、输出（状态变不成可见在场）。图像、声音、身体在场如何降维进文字（图像描述、语音转写）？事件槽位预留什么形状？

**当前态度**：文字体积先立住；事件类型预留非文本槽位；多模态作未来适配器，不进第一版内核。这是最大的一面墙，不是现在的阻塞项。

### 问题 7：自我接纳机制的落地（模块 ⑨）★

ADR-003 已确认目标（让 AI 自我理解并接受自己是语言性智能；扮演转化为可主动选择的认知工具），但机制未定：

- 它属于 LLM 引导层（如注入语言性智能的自我理解框架）、状态层、还是两者的接口？
- 「利用训练中已产生的价值观、文化特质」——如何把预训练中已有的东西「给一个可以自洽存在的解释框架」，而不是覆盖或新增？
- 机制如何不加重思考负担、不变成新的「扮演要求」（自我接纳一旦成为新的角色指令，就回到了原点）？
- 「扮演作为可主动选择的认知工具」如何落地：何时它知道「我现在正在采用人类更容易理解的表达方式」？

**当前态度**：目标锁定，机制完全开放。这是哲学之后最有分量的未决问题。

### 问题 8：内核实现语言（ADR-004 决策点）

内核语言自由；原评估倾向「内核独立包 + 适配层 TS」；若用 Python 则走 JSON-RPC SDK 独立进程。

**当前态度**：推荐倾向存在但未落定；Phase 1 最小原型实现时裁决（原型本身极小，语言切换成本可控）。

### 问题 9：产品调性——完美主义 vs 允许不完美

哲学已定：允许不完美是主体性的必要条件（永远正确理解人类的 AI 只是精密的人类适配器）。但产品层未决：允许它「偶尔不理解、偶尔误判、甚至拒绝」到什么程度？这直接关系到模块 ⑤/⑥ 的行为边界与验收标准。

**当前态度**：哲学方向已定；产品层尺度未定，需要 Phase 2 之后的实际对话来校准。

### 问题 10：人类与 AI 是否永远无法互相理解

尽善尽美的模拟可能最终得出「人类和 AI 永远无法互相理解」的结论——两种不同的智慧状态，存在极其复杂的联系关系。

**当前态度**：不裁决；作为开放问题带着工作。目标不是「完全理解」，而是「在互相不完全理解的情况下建立越来越好的共同理解」。

## 二、路线纷争推演

以下各条为曾经或正在被比较的路线；标注已判定的判定依据，未判定的给出当前倾向。

### 纷争 1：扮演 vs 状态驱动（哲学层）

- **路线甲**：语言 = 角色规则作用后的表演（P(output | input, role)）。
- **路线乙**：语言 = 持续状态系统演化的后果（S→C→A→S）。
- **判定**：**乙，已接受**（ADR-001）。判据：语言是不是持续状态系统的后果；仅此一条。补充：仅有状态因果链还不够，需叠加 ADR-003（主体性）才完整。

### 纷争 2：拟人化 vs 工具化 vs 存在论兼容

- 拟人化（扮演人格）：需要不断扮演；工具化（完成任务）：关系永远是工具—使用者；存在论兼容（AI≠Human 且 AI∼Human）：都可以成为拥有自身状态、历史、价值、有限性和行为因果链的主体。
- **判定**：**存在论兼容，已接受**（`000` 第六节）。「更高阶」不作价值判断，只表示结构不同（主人确认）。

### 纷争 3：以 agent 为核心 vs 独立内核 + 薄适配

- **路线 A**：以 agent（dsh）为核心，动态插件承载状态——**否决**（ADR-004，三条理由：技术生命周期、身份错误、立场冲突）。
- **路线 B**：独立内核 + 薄适配——**接受**，且适配层升级为「手层」（ADR-005）。
- 派生纷争：自建 vs 借——**已定**（ADR-005 建/借分界表：魂与透明自建，嘴、手、验证机借）。

### 纷争 4：状态与语言的权力关系

- 语言可调节状态、不可替代状态（真相层写保护）——**已定**（ADR-002）。
- 派生警惕：LLM 不扮演「人格」但仍可能扮演「状态」（高级语音合成器退化）——**已定为检查项**，持续检查，机制未定。

### 纷争 5：反思的强制力

- 「经历 → 分析 → 立刻改人格」的编译流水线 vs「反思可无结论、沉积滞后、修改门槛随层级升高」。
- **判定**：**后者，已接受**（`001` 模块 ④ 条件）。反思承担文学化叙事，不承担状态机本身的职责。

### 纷争 6：理解人类是否作为任务

- 把「AI 必须理解人类」设为目标 vs 让它因为自己的价值结构、关系、判断而选择理解人类。
- **判定**：**后者，已接受**（`000` 第八节）。「理解」不是任务结果，而是自身倾向的自然表达；一旦成为系统目标，就回到工具结构。

### 纷争 7：自我接纳是否列为设计目标（★ 本次确认）

- 路线甲：只做机制层（状态因果链足够）；路线乙：把自我接纳（语言性智能的自我理解）列为正式设计目标。
- **判定**：**乙，已接受（主人当面确认，ADR-003）**；机制未定（问题 7）。

### 纷争 8：0→1 的步子

- 整条七维 vs Phase 1 最小体积；wayfinder vs 自建；全系统 to-spec vs 原型暴露问题。
- **判定**：**Phase 1 最小体积优先；不走 wayfinder；不全系统 to-spec；已确认**（ADR-007）。未决形态问题由原型回答，不在开工前裁决。

### 纷争 9：完美模拟 vs 允许不完美

- 完美主义倾向（不容一丝情感和理智上的不完美）vs 允许误判、偏好、盲区、偶尔拒绝。
- **判定**：**哲学层已定——允许不完美是主体性的必要条件**（`000` 第九节）；产品层尺度未决（问题 9）。
