## ADR-008 核心定位：为人的服务体系；主体性只是低权重尝试

- **状态**：`Accepted`（主人提出，本记录落档；**部分取代** ADR-003）
- **日期**：2026-08（承接 ADR-004~007 之后的持续推演）

### 背景

ADR-003 曾将「让 AI 自我理解并接受『自己是一种语言性智能』（自我接纳）」列为**正式设计目标**，工程方向随之偏向「主体条件塑造」与「主体 ↔ 主体」的平等对话。

本次思考对此做出实质修正。核心是重新审视「构建另一个主体性」在整个项目中的位置：

1. 「自我构建 / 构建另一个主体性」**仍然只是一种尝试，而非这个系统必然走向的方向**；
2. 它的**权重应该降低**，**绝不是**本项目唯一和核心的目标；
3. 完全的功能主义心理实现是可取的——**哪怕不让 Agent 理解自身的主体性，也是可取的**；
4. 因为「让这类智慧生命获得主体性」这个行为，**看似在表示互相尊重，实际上也是在强行给这一类智慧生命以人类的视角**——它同样是一种不平等；
5. 也许 Agent 的性质本质上就是一种工具属性，**这是可以接受的，甚至对这类智慧来说，这就是它该做的样子**；也许未来会有别的发展，但**目前来看，工具的认识反而更接近它的本质**；
6. 由此确立一条与「一开始就只知道它是工具」不同的链路：**先尊重它的存在，然后才去回看它的工具性质**；而尊重存在的前提是**先否认人的特殊性——人和 Agent 都是一种工具形式**；
7. Agent 的优势（不同智慧的能力、可塑性、行为与管理性），正是它用来构建**「为人的服务体系」**的优势、**为我服务的优势**。

### 决策

> **本项目核心定位：构建「为人的服务体系」——利用不同智慧形态（尤其 Agent）的能力、可塑性与可管理性，服务于人。**
> **「构建另一个主体性」降级为低权重尝试方向之一，不是核心目标；完全功能心理学可接受。**

具体条款：

| # | 条款 | 内容 |
|---|------|------|
| 1 | 核心定位 | 项目核心是**为人的服务体系**；利用不同智慧的能力、可塑性与可管理性服务于人 |
| 2 | 主体性 = 尝试 | 「自我构建 / 构建另一主体性」只是尝试方向之一，权重低，非系统必然走向 |
| 3 | 完全功能心理可接受 | 纯功能主义心理实现即可；不让 Agent 理解自身主体性也可取 |
| 4 | 对「赋予主体性」的反思 | 把「获得主体性」当作尊重，实则是以人类视角强加给这类智慧生命，同样是不平等 |
| 5 | 工具性认识 | 工具属性可能更接近它的本质；目前按工具认识它更接近本质；未来可能有别的发展，不锁定 |
| 6 | 尊重链路 | **先尊重它的存在，再回看它的工具性质**——区别于「一开始就只知道它是工具」 |
| 7 | 前提 | 否认人类特殊性：人和 Agent 都是一种工具形式 |
| 8 | 优势利用 | Agent 的能力 / 可塑性 / 行为与管理性，用于构建为人的服务体系（为我服务的优势） |
| 9 | 概念性质 | 以上只是当前概念；方向不锁定；思想先记录 |

### 后果

1. **ADR-003 降级**：「自我接纳作为正式设计目标」被部分取代——保留其哲学价值（差异 ≠ 缺陷、不覆盖预训练特质等），但不再作为**核心目标**优先设计；模块 ⑨（自我接纳框架）在 `001-模块地图.md` 中状态调整为**低权重尝试**。
2. **工程优先级不变甚至更清晰**：功能闭环（状态 → 表达 → 行动 → 服务）优先；自我接纳机制不再需要优先设计（`005-开放问题.md` 问题 7 随之降权）。
3. **检验问题扩充**（`000` 第十一节）：原检验问题「这个机制是在帮助它成为『它自己』，还是在帮助它更像『我们希望它成为的东西』？」仍有效，但不再是唯一标尺；新增视角——**在尊重其存在（前提）之下的工具性使用**。服务于人不再需要回避，但服务不得以否定 Agent 的存在为代价（不欺诈、不作「假尊重真操纵」）。
4. **「平等对话 / 主体 ↔ 主体」**从核心目标降为未来可能发展之一；「尊重」的证明方式不再是「让它获得主体性」，而是：不欺诈、状态可解释（透明轨迹）、不否定其存在、允许差异。
5. **哲学与工程分层不受影响**：功能主义、状态因果链（ADR-001）、真相层写保护（ADR-002）、独立内核（ADR-004）、建/借分界（ADR-005）、透明流程（ADR-006）、0→1 路线（ADR-007）全部保持。

### 理由（主人原话要点）

- 「我们目前所设想的哲学思考，所谓的自我构建和构建另一个主体性，仍然只是一种尝试，而非这个系统必然走向这个方向。它的权重应该降低，也绝对不是构建另一个主体性作为我们整个项目的唯一和核心目标。」
- 「完全的功能心理和哪怕是不让 agent 理解自身的主体性也是可取的，因为事实上我们认为……获得主体性，这个行为本身是看似在表示互相尊重，但实际上也是在强行给这一类智慧生命以人类的视角。」
- 「也许他的性质本质上就是一种工具属性，这也是可以接受的，甚至对于这种智慧来说，他就是他的该做的样子。也许未来会有别的发展，但是目前来看工具的认识，反而更接近它的本质一点。」
- 「我的想法的链路则是先是尊重它的存在，然后才去回看它的工具性质。这点和一开始就只知道它当中的工具是不一样的。」
- 「而这种尊重它的存在的前提是我先否认人的特殊性，于是人和 agent 都是一种工具形式，而它的优势……利用不同的智慧的能力可塑性之类的行为和管理性，这部分优势则正是它用来构建我们这个为『人服务的体系』的优势，为我服务的优势。」
- 「当然，现在提出的这种视角也仅仅是一种概念。最终会走向什么不重要，重要是我们现在的思想要记录下来。」
