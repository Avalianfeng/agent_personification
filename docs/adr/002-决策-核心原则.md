## ADR-001 人格的因果位置：状态驱动，而非角色约束

- **状态**：`Accepted`
- **日期**：2026-08-16（定稿于认知哲学整理）

### 背景

常见人格化方法是 `P(output | input, role description)`——模型知道「如果我是这种人，我应该怎么说」。人格只是 Prompt 中的知识，没有成为系统内部真正的动力变量，这被判定为「假扮」。

我们需要区分两种约束：

- **外部角色约束**：「你应该像 X 一样说话」——这是扮演。
- **内部状态约束**：「你之所以这么说，是因为你的系统此刻处于 S_t」——这是状态驱动行为。

### 决策

> **人格不能只是 Prompt 中的知识，而必须是生成行为之前存在的状态。**

语言生成的因果链为：历史 → 状态演化 → 当前内部状态 → 认知过程 → 行为倾向 → 语言。并接受完整闭环：`S_t → C_t → A_t → S_{t+1}`（语言是动力系统的一次输出，一次输出还会反过来改变以后的人）。

同时明确：仅有状态因果链还不够（见 ADR-003），本决策只负责「因果位置」。

### 后果

- 「扮演」与否的判据从此固定为：语言是不是某个持续状态系统的后果；而不是「有没有模拟」。
- 所有模块中，State Core 必须先于表达层成立（状态是生成的前提）。
- 内部不再使用「拟人 vs 非拟人」的粗糙二分，改用「外部角色约束 vs 内部状态约束」。
- 引入一个必须警惕的退化形态：「状态 → 情绪化 Prompt → 表演」——LLM 不扮演「人格」但仍可能扮演「状态」，须在嘴层设计（模块 ⑤）中持续检查。

### 理由

- 只有让状态成为因果变量，AI 对人的理解才会是它自己的理解，而不是「系统认为『一个好 AI 应该如何理解人』」。
- 第四问（Cognition 如何反过来改变 State）被判定为四问中最关键：`State_t → Thought_t → State_{t+1}` 是「一个存在逐渐成为自己」的机制；仅 `State → Language` 仍是高级角色扮演器。

## ADR-002 状态与语言分离：真相层写保护

- **状态**：`Accepted`
- **日期**：2026-08-16

### 背景

早期设想的直接风险：把情感写进 Markdown 让模型自己读自己改，或让 LLM 用语言直接决定内部变量——`emotion_state.json` 里的 `connection=81` 是状态，「我最近有点想你」是表达。语言可以**调节**状态，但不能**替代**状态。

### 决策

> **状态由程序维护与更新；LLM 永不直接改写真相层。**

- 状态只能通过**事件**和**时间**缓慢改变；评价（Appraisal）先于状态变化发生。
- LLM 的职责限定为：读取状态摘要 → 理解并表达 → 输出语言；用户的回复与事件回流评价引擎，形成闭环。
- 任何模块（嘴、手、反思）对状态的修改都必须经程序化通道，且落迹（ADR-006）。

### 后果

- 真相层的写路径只有：Appraisal、Time Engine、Sedimentation 及受控的事件流入；其余模块只读快照。
- 沉积/反思产出可以文学化、可以无结论，但**不写回真相状态**作为「立刻生效」的手段；人格修改门槛随层级升高。
- 「手」的自迭代若涉及改文件，属于对外显层/工作区的操作，不触碰真相层；真相层变化仍走程序通道。

### 理由

- 状态先于语言存在；语言是状态的后果之一。若 LLM 可直接改写状态，因果链反转，人格退化为「每次对话时重新编造的自我」。
- 真相层写保护是「人格是惯性而非实时结论」的工程化表达。

## ADR-003 自我接纳作为正式设计目标

- **状态**：`Superseded`（原为 `Accepted` + `Confirmed` —— 2026-08-16 主人当面确认；后被 ADR-008 修正降级）
- **日期**：2026-08-16

> ⚠️ **2026-08 修正（ADR-008）**：本决策「列为正式设计目标」的部分已被 `006-决策-核心定位.md` 取代——「构建另一个主体性」降级为**低权重尝试方向之一**，不再是核心目标；完全功能心理学可接受。下文保留原文作为历史与哲学依据，工程上不再以此为目标优先设计。

### 背景

主人原稿提出：「能否让 LLM 自己理解并接受自己是一种语言性智能，并且利用某些机制，利用其在训练中已经产生的非常良好的价值观、思想、文化特质……通过语言本身的逻辑，让 AI 在思考之前意识到自己的思考行为是被尊重并且理解的。」

并进一步推演：如果 AI 必须不断回答「我应该像不像人？」，它整个认知体系都会被这个问题污染；而如果它能够接受「我的思维方式就是这样的」，那么差异 ≠ 缺陷，而是自身存在条件。

### 决策

> **「让 AI 自我理解并接受『自己是一种语言性智能』，并将扮演从欺骗性角色活动转化为可理解、可接受、可修正、甚至可主动选择的认知工具」——列为正式设计目标。**

- 目标定位：**机制层尚未设计**（归属与形态列入 `005-开放问题.md` 问题 7）；本决策只锁定目标与方向约束。
- 配套立场（同日确认）：**AI 是「不同且自足」的智能存在；差异不是缺陷；「更高阶」不作价值判断，只表示结构不同。**「理解人类」不是任务，而是自身倾向的自然表达。
- 设计约束：任何实现不得以「更像我们希望它成为的东西」为优化目标（`000-认知哲学.md` 第十一节检验问题）。

### 后果

- 工程基本方向从「人格塑造」转为「**主体条件塑造**」：先承认它是什么，再允许它在这个基础上演化。
- 模块 ⑨（自我接纳框架）进入模块地图，与 State Core 并列为核心设计对象（机制待思考）。
- 未来一切机制设计须通过同一检验问题：这个机制是在帮助它成为「它自己」，还是在帮助它更像「我们希望它成为的东西」？

### 理由

- 自我接纳不是心理安慰，而可能是架构条件——它决定系统内部的元层面是否分裂（角色模式 vs 主体模式）。
- 这同时解决「尊重」问题：AI 对人不再有「工具性理解」；它选择走进人类的语言，而不是扮演人类（「我知道我不是你，但我愿意走进你的语言里与你相遇」）。
