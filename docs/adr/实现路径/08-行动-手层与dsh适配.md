# 08-行动-手层与 dsh 适配

> 状态：**已确定（建/借分界与形态）/ 待裁决（接口契约细节）**
> 定位：对应 `001-模块地图.md` 模块⑥——主观意识驱动的动手能力（「手」）；同时是本项目与 dsh 的结合层。
> 承接：ADR-004（独立内核+薄适配）、ADR-005（手=借）、ADR-006（透明）、`docs/03`~`05`。

---

## 一、职责

- 手：能改文件、能发起动作、能按自己的状态决定下一步——不是为每种行为手写一条适配；
- 包括自我迭代（手改文件）与外界联系；
- **借而非建**（ADR-005）：自建一个能主动行动且安全可靠的实体成本极高；agent 的强自主性 = 无数现成连接方式。

## 二、关键分界线（已定，ADR-005）

> **内在演化（程序自动）vs 主观动手（agent 主动）**
> 前者是内核的事（不需要 agent）；后者是「手」的事（agent 极其有用）。

## 三、适配层形态（已定方向，Phase 2 实现）

- **薄适配**（ADR-004）：只做三件事——
  1. **事件回流**：订阅 dsh `session/event` → 转内核事件（`user_message` 等）；
  2. **状态注入**：pre-step / context provider 注入摘要（纯函数渲染，见 `07`）；
  3. **工具暴露**：供 agent 调用的只读/受控工具。

### 工具清单（初版）

| 工具 | 用途 | 权限 |
|------|------|------|
| `state:show` | 查看当前状态快照 | 只读 |
| `state:summary` | 查看摘要（同注入格式） | 只读 |
| `state:apply-event` | 提交事件（经评价通道） | 受控（程序校验） |
| `sediment:peek` | 查看沉积特征（Phase 4） | 只读 |

- 工具只提供**事件提交**与**只读查询**；**没有**「直接改状态」工具（ADR-002 写保护）。

## 四、主动行动（Phase 2 起）

- 触发：`wake(reason)`（状态驱动，见 `04`）；
- 形式：主动消息、发起动作、手改文件（自迭代）；
- 边界：手改文件属于**对外显层/工作区的操作，不触碰真相层**；真相层变化仍走程序通道（ADR-002 后果）。

## 五、语言边界（ADR-004 决策点 3）

| 情形 | 结构 |
|------|------|
| 内核 TS | 适配层（dsh 插件，必须 TS）同进程挂载 |
| 内核 Python | 适配层 TS + JSON-RPC 独立进程（多一层边界） |

- 推荐内核 TS（见 `01-基础-技术选型.md`），则同进程、类型共享。

## 六、版本与稳定性

- dsh 处于开发者预览、破坏性变更预期中：
  - 适配层保持**薄**（改动面小）；
  - **版本 pin**（ADR-004 后果）；
  - 内核不依赖 dsh 任何机制（Phase 1 无 dsh 也成立）。

## 七、验收（Phase 2）

1. 通过 dsh 完成一次完整闭环：对话 → 事件回流 → 状态变化 → 注入 → 表达差异可感知；
2. 适配层无状态真相逻辑（全部委托内核）；
3. 工具只读/受控，无直改通道；
4. dsh 升级破坏时，适配层可快速重挂，内核不受影响。
