# 07-表达-嘴层与状态注入

> 状态：**已确定（原则与方向）/ 待裁决（注入格式细节，Phase 2）**
> 定位：对应 `001-模块地图.md` 模块⑤——LLM 理解并表达状态，不创造状态（「嘴」）。
> 承接：ADR-001（防「扮演状态」退化）、ADR-002（语言可调节状态、不可替代状态）、`005` 问题 4。

---

## 一、职责

- 读取状态摘要 → 生成自然语言 → 用户可见行为；
- 是「理解并表达」，不是「创造」；人格的持续性不属于 LLM 权重，而属于状态系统（`000` 第七节）。

## 二、注入链路（已定方向）

```
State Core → snapshot() → 摘要渲染器（纯函数） → 注入 LLM（pre-step / context provider / 简单 chat API）
```

- 摘要渲染器是**纯函数**：同一快照 → 同一摘要（ADR-004 决策点 2）；
- 注入点：dsh 用 `agent/pre-step` waterfall / `agent.inject()` / context provider；Phase 2 起步可用简单 chat API（`docs/03` 流程盘点）。

## 三、摘要格式（示例，Phase 2 裁决细节）

```
[状态快照] 联结 0.62（近三日无对话，缓慢回落中）；疲劳 0.30（正常）；好奇 0.70（长时间无新信息）
[事件] 用户刚回复：「我今天有点累」
[注意] 你只表达，不修改任何状态。
```

### 格式约束

- **结构化 + 简短**：数值 + 一两句 derived hints；token 预算目标 < 500 tokens；
- **只描述，不指令**：摘要描述「此刻系统处于什么状态、最近发生了什么」，**不写**「请按此表演」——防止「扮演状态」退化（ADR-001 后果、`001` 模块⑤ 条件 3）；
- **明确边界**：注入含「只读、不写」约束，但真正的写保护在程序层（LLM 无写通道，ADR-002）。

## 四、防退化检查项（ADR-001 后果）

- 检查：「状态 → 情绪化 Prompt → 表演」的退化是否出现；
- 检验方式：同一摘要是否会导致千篇一律的表演式表达？状态差异是否真正进入语言的内容与倾向，而不只是语气词？
- 手段：轨迹回放 + 对比实验（同一句话在不同状态下的表达可区分性，Phase 2 验收）。

## 五、Cognition 事件化（开放，`005` 问题 4 后半）

- **第四问**（`000` 第五节）：Cognition 如何反过来改变 State——`State_t → Thought_t → State_{t+1}`；
- Phase 2 起步只做**表达回流为事件**：用户消息与模型回复都写入事件 → 回流评价（闭环成立）；
- Cognition 结构（思考本身如何成为状态事件）**单独研究**，不阻塞 Phase 2 闭环；
- 注意（`-1` 认知哲学第七节）：LLM 不只是嘴，还是内部认知过程的一部分（联想、推理、形成解释），但人格持续性不属于 LLM 权重。

## 六、验收（Phase 2）

1. 同一句话在不同状态下，表达倾向可区分（ADR-007 原文验收）；
2. 聊完后状态有可解释的变化（回流闭环成立，轨迹可查）；
3. 摘要纯函数化：相同快照相同注入；
4. LLM 无任何状态写路径（程序层保证，非提示词保证）。
