# 01-基础-技术选型

> 状态：**部分已定 / 部分待裁决**（每项标注）
> 定位：内核的「技术手段」基础——语言、依赖、时间表示、配置、对外接口轮廓。
> 承接：ADR-004（独立内核+薄适配、语言边界决策点）、`005-开放问题.md` 问题 8。

---

## 一、决策项

### 1. 内核独立性（已定，ADR-004）

- **决策**：内核是独立包，与任何 Agent 框架（dsh 等）**零依赖**；文件持久化；真相层在内核内。
- **后果**：Phase 1 完全不需要 agent 即可运行；框架可替换；dsh 破坏性变更不影响内核。
- **理由**：依附于 agent 的状态不是状态，是会话变量；「人格的持续性不属于 LLM 权重，而属于状态系统」。

### 2. 内核语言（待裁决，`005` 问题 8）

- **候选**：
  - **TypeScript**：与 dsh 适配层同语言，可共用类型定义；单语言栈、边界最少；Phase 1 原型极小，TS 足够。
  - **Python**：数据/科学计算生态好，但需走 JSON-RPC 独立进程与 dsh 通信（ADR-004 决策点 3），多一层边界。
- **推荐**：**TypeScript**（理由：单语言栈、类型可共享、无进程边界；后续若要 Python 可在独立包内替换，适配层不变）。
- **决策规则**：Phase 1 实现时裁决（原型极小，切换成本可控）；若选 Python，适配层仍为 TS。

### 3. 依赖策略（已定）

- **决策**：Phase 1 内核**零运行时依赖**（纯标准库）；存储用 JSON 文件，不用数据库。
- **后果**：可移植、可审计、无供应链风险；后期如需 SQLite（如轨迹量增大）再评估，不改变接口。
- **理由**：最小闭环原则（ADR-007）；魂便宜（`docs/05`），不值得上重装备。

### 4. 时间表示（已定）

- **决策**：存储用 **Unix epoch 毫秒整数**（`number`）；展示与日志用 ISO-8601 UTC 字符串；所有演化计算基于**时间差 Δt**。
- **后果**：补算 = Δt 的纯函数（ADR-004 决策点 1）；无时区歧义；可重放。
- **理由**：时间引擎的数学对象是 Δt，不是墙钟；绝对时间戳 + 差值计算最简。

### 5. 配置（已定，最小集）

- **决策**：单个 `config.json`（或 `config/` 目录内少量文件）：变量定义（名称、范围、基线、衰减参数）、存储路径、可选项（LLM seam 地址等）。
- **后果**：参数与代码分离；调参不改代码。
- **理由**：从简原则——不引入配置框架。

### 6. 内核对外接口轮廓（已定方向，签名见各模块文件）

| 接口 | 用途 | 阶段 |
|------|------|------|
| `snapshot()` | 只读状态快照（给摘要渲染器 / 适配层） | Phase 1 |
| `applyEvent(event)` | 事件进入（→ 时间补算 → 评价 → 状态更新） | Phase 1（简化）/ Phase 3（完整） |
| `tick(now)` | 显式推进时间（补算 + 落迹） | Phase 1 |
| `showState()` | CLI / 工具：查看状态 | Phase 1 |
| `summary()` | 摘要渲染（纯函数） | Phase 2 |
| `replay(from)` | 轨迹重放校验 | Phase 2 |
| `wake(reason)` | 主动唤醒入口（供外部守护/cron 调用） | Phase 2 |

- **边界**：内核**不知道** LLM / dsh 的存在；它只暴露上述接口，由适配层接入外部世界。
- **验收**：内核可脱离任何框架独立运行；用 CLI 即可完成「过一天、聊一句、看状态变」。

## 二、后果与约束

- 适配层语言：若内核 TS，适配层（dsh 插件，必须 TS）同进程挂载；若内核 Python，走 JSON-RPC 独立进程。
- 版本控制：内核与适配层分离发布；适配层 pin dsh 版本（ADR-004 后果）。
- 本文件的裁决时机汇总：
  - 内核语言 → Phase 1 实现时；
  - 其余项 → 已定，Phase 1 直接执行。
