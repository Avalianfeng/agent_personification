## 一句话立场

- **不是**把 Agent 变成假人来填补缺席的陪伴。  
- **而是**知道人是何种功能结构，搭建体系去验证能否拟合；人类与 Agent 都是有限体系上的生命形式，可以追求更平等的共同对话。

---

## 现阶段做什么 / 不做什么

**做**：文件夹与持久化、定时、需求与情绪变量、内部演化；用简单对话 API 验证。  

**不做（现阶段）**：绑定某一 Agent 框架的能力细节；用 Prompt 表演代替状态；先攻非文字多模态（预留接口即可）。
