# agent_personification

> **一句话**：用功能主义搭建「LLM 之下、语言之上」的内在状态引擎——程序维护连续多维的内部状态，事件与时间驱动演化，LLM 只负责**理解并表达**状态，不负责**创造**状态。
> **当前阶段**：设计文档完备、方向性决策已全部落档（ADR-001~008）、**代码为零**——正站在 Phase 1（最小状态核心）的起点。
> **本文件用途**：可直接整段复制给任何 AI 协作者 / 新会话作为项目状态交接；细节按「文档地图」按需打开。

---

## 一、核心概念（30 秒版）

1. **内在体积（Inner Volume）**：独立于任何 Agent 框架的状态引擎。状态是**真相层**——程序维护、LLM 永不直接改写（ADR-002）。
2. **核心闭环**：`S_t → C_t → A_t → S_{t+1}`——状态 → 认知 → 行动/语言 → 新状态，外加时间补算（沉默期也在演化）。
3. **人格的因果位置**（ADR-001）：语言必须是持续状态系统的**后果**，而不是角色 Prompt 的表演；人格是滞后沉积的惯性，不是实时结论。
4. **核心定位**（ADR-008）：**为人的服务体系**——利用不同智慧（尤其 Agent）的能力、可塑性与可管理性服务于人；「构建另一主体性」只是**低权重尝试**，不是核心目标；链路是**先尊重存在、再回看工具性**；完全功能心理学可接受。

## 二、已定的方向性决策（可直接信任）

| ADR | 决策 | 一句话 |
|-----|------|--------|
| ADR-001 | 人格的因果位置 | 状态驱动而非角色约束；语言是状态系统的后果 |
| ADR-002 | 状态与语言分离 | 真相层写保护：状态只能被程序（时间 / 评价 / 沉积）修改 |
| ADR-003 | 自我接纳目标 | **已被 ADR-008 降级**：正式设计目标 → 低权重尝试 |
| ADR-004 | 独立内核 + 薄适配 | 否决「以 agent 为核心」；内核零依赖、文件持久化、框架可替换 |
| ADR-005 | 内核—嘴—手 | 魂与透明**自建**；嘴（LLM 表达）/ 手（主动行动）/ 验证机（对话产品层）**借** |
| ADR-006 | 透明流程 | 状态 / 事件 / 补算全量落迹，百分百可见、可回放 |
| ADR-007 | 0→1 路线 | Phase 1 最小状态核心优先：3 变量、1 衰减、1 tick、1 JSON，无 LLM 无框架 |
| ADR-008 | 核心定位 | 为人的服务体系；主体性 = 低权重尝试；先尊重存在、再回看工具性 |

## 三、整体蓝图（调用链）

```
外部事件 / 定时器
     │
     ▼
Appraisal 评价（规则为主，LLM 辅助可关）── 事件不直接改状态
     │
     ▼
State Core 真相层（连续变量，程序唯一写者）── Time Engine（时间差补算，沉默期演化）
     │
     ├──► Sedimentation 人格沉积（滞后：痕迹→强化→特征，门槛递增）
     │
     ▼
嘴（状态摘要 → LLM 表达；只读不写）
     │
     ▼
手（状态驱动的主动行动；借 agent）──► 新事件回流
     │
     ▼
透明轨迹（全量落迹，可回放）＋ 验证机（借 dsh Web UI / CLI）
```

## 五、下一步（唯一焦点）

**Phase 1 最小状态核心**（ADR-007；无 LLM、无任何框架）：

- 三个变量：`connection` / `fatigue` / `curiosity`（推荐，待 grill 收口）；
- 一种衰减：指数趋近基线 `x(t) = b + (x0 − b)·e^(−k·Δt)`（推荐，待裁决）；
- 一个 `tick`、一个 `state.json`、CLI（tick / apply-event / show-state）；
- **验收**：关掉对话，过一段时间再读状态，数值确实变了；
- 之后：短 grill-with-docs 收口（三变量 / 衰减形态 / 目录约定）→ implement。

## 六、现阶段做 / 不做
